# Plataforma Atleta — MVP inicial

Protótipo navegável de uma plataforma centrada no atleta para registrar e apresentar seu histórico esportivo individual.

## Estado atual

Esta primeira entrega é um protótipo de interface em HTML, CSS e JavaScript, com dados fictícios. Ainda não possui autenticação, banco de dados, armazenamento real de mídia ou integração com serviços externos.

## Como executar

1. Baixe ou clone este repositório.
2. Abra `index.html` diretamente no navegador.

Opcionalmente, use a extensão Live Server do VS Code para executar localmente.

## Áreas demonstradas

- Dashboard do atleta
- Perfil e identidade esportiva
- Histórico de clubes e temporadas
- Avaliações físicas e evolução
- Partidas e estatísticas
- Galeria de mídia
- Privacidade e compartilhamento

## Diretrizes do produto

- O histórico pertence ao atleta e deve acompanhá-lo independentemente dos clubes.
- Futebol e futsal são as modalidades iniciais; a arquitetura futura deve permitir expansão.
- Campos esportivos e medidas devem ser configuráveis, evitando estruturas rígidas por modalidade.
- O atleta controla individualmente o que deseja tornar público.
- Dados não coletados devem ser diferenciados de valores iguais a zero.
- Estatísticas de desempenho devem refletir os dados efetivamente registrados, sem inferências automáticas não solicitadas.
